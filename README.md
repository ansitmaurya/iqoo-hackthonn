## 🚀 Quick Start Guide

### Prerequisites
- **Node.js**: v18.0 or higher
- **Package Manager**: npm, yarn, or pnpm

### 1. Installation
```bash
# Clone or navigate to the repository directory
cd "senital flow"

# Install all dependencies
npm install
```

### 2. Launch Local Development Server
```bash
npm run dev
```
Open **[http://localhost:5173/](http://localhost:5173/)** in your browser. The cinematic cyber intro will boot up and the real-time detection pipeline will initialize.

### 3. Production Build & Strict TypeScript Validation
```bash
npm run build
```

## 🧠 Deterministic Fraud Rule Scoring Engine (`riskEngine.ts`)

TraceGuard evaluates transactions against a 7-factor mathematical and heuristic rule matrix:

| Rule ID | Rule Identifier | Risk Weight | Mathematical Condition & Trigger Logic |
| :--- | :--- | :---: | :--- |
| `RULE-01` | **Rapid Velocity Burst** | `+40 pts` | $\ge 3$ transactions from the same account within a 2-minute sliding window. |
| `RULE-02` | **Impossible Travel (Geo-Velocity)** | `+50 pts` | Haversine distance $>200\text{ km}$ with physical velocity $>800\text{ km/h}$ between consecutive events. |
| `RULE-03` | **Amount Deviation Anomaly (Z-Score)** | `+35–45 pts` | Transaction amount deviates by $\ge +3.0\sigma$ from user's historical mean ($\mu$). |
| `RULE-04` | **Regulatory Avoidance (Structuring)** | `+45 pts` | Amount in the $\$9,000$ to $\$9,999$ range designed to evade the $\$10,000$ CTR threshold. |
| `RULE-05` | **Unrecognized Tor Device** | `+35 pts` | Transaction $> \$2,500$ originating from an unregistered Tor exit node or proxy. |
| `RULE-06` | **Off-Hours High-Risk Transfer** | `+30 pts` | Nocturnal execution (00:00 – 04:30 AM local) in `CRYPTO_EXCHANGE` or `WIRE_REMITTANCE`. |
| `RULE-07` | **Mule Watchlist Association** | `+50 pts` | Direct link to a frozen counterparty or flagged syndicate ring. |

### Composite Risk Scoring Scale
- **`CRITICAL` (80–99 pts)**: Immediate automated `BLOCK` recommendation + Emergency SOC alert.
- **`HIGH` (60–79 pts)**: Automated `REVIEW` recommendation + Alerts Queue ingestion.
- **`MEDIUM` (35–59 pts)**: Flagged for analyst surveillance.
- **`LOW` (0–34 pts)**: Automated `ALLOW` settlement.
